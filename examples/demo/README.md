# Demo report

[`report/report.md`](report/report.md) is a report of made-up emails, to
show what `imap-statistics` produces. The data comes from the
[`demo_data`](../demo_data.rs) example instead of IMAP servers.

After a change of the report, generate it again and commit the result:

```sh
examples/demo/generate.sh
```

CI checks that the committed report is up to date.
